# Completing ForestMind

Updated October 26, 2026 for the **v0.7.0 research bridge**. The bounded local monitoring application passed its v0.6 acceptance checks. This build adds measured multimodal inputs, independent-reference dataset preparation, partial supervision and offline native execution; 814 regression checks and 42 final presentation/radar checks passed. The full ecological early-warning proposal is not complete. The user confirmed no verified reference data is available yet. Software behavior, deployment readiness and scientific predictive validity have separate acceptance gates. Current verification and its limits are recorded in `VALIDATION.md`.

## What the application provides

The dashboard supports explicit attributed place search, coordinate/map selection and exact boundary confirmation. Sentinel-2 collection freezes its plan, bounds downloads and storage, records quality failures and gaps, and preserves accepted observations across cancellation, resume and restart. Saved areas can refresh and run local schedules while the service is running.

Connected analysis retains immutable geometry, observation cutoff, accepted source hashes, method/context/model versions and exports. It computes measured optical change, eligible baseline forecasts, seasonal recovery diagnostics and classified-cover topology, including patch compactness only where the whole boundary is observed. Actual ERA5 climate, dated ESA WorldCover and matched Sentinel-1 RTC pairs can be collected as context. Climate includes same-day paired precipitation minus reference ET0 with partial periods and missingness retained. Valid radar and climate evidence can now be aligned to optical dates with independent masks, fixed units and past-only matching. Only models explicitly registered for these inputs receive them. Five-year comparisons are explicit hypothetical indicator sensitivities. Alert thresholds, supporting observations, review notes and lifecycle controls remain separate from ingestion/freshness failures.

The real-reference converter accepts independent sources and any supported combination of labels. It enforces protected spatial/temporal partitions, training-only normalization and frozen artifact/config contracts. Unknown labels contribute no loss or accuracy; unsupported prediction outputs are withheld. Both native encoders passed CPU architecture/state-roundtrip/forward checks with random states, blocked network and the documented runtime. These are software checks, not trained ecological models or evidence of pretrained benefit. See [TRAINING_DATA.md](TRAINING_DATA.md), [MULTIMODAL_INPUTS.md](MULTIMODAL_INPUTS.md) and [NATIVE_MODEL_AUDIT.md](NATIVE_MODEL_AUDIT.md).

The real Tapajós browser pilot began with two accepted observations; a subsequent bounded refresh/cancel/resume exercise added two more. The saved Tamil Nadu area retains its one actual observation, and an additional Germany pilot has one. Actual climate, WorldCover and radar context have also been collected, and saved areas/context survived restart. These checks demonstrate provider and application paths across several locations; they do not establish sufficient time series or worldwide ecological transfer. Earlier one-scene and eight-month imports remain preserved. Full database/source/workflow backups were created and verified. Final browser, immutable-export, responsive, regression and installed-package evidence is recorded in [VALIDATION.md](VALIDATION.md).

## Next scientific milestone

Freeze one measurable disturbance or degradation outcome, its intended use, forecast horizon, reference source, uncertainty rules and evaluation protocol before tuning. Acquire a sufficiently long, quality-checked history and independently review the reference labels. Use the existing experiment harness to establish conventional baselines, then compare any eligible pretrained or multimodal model on the same protected examples. Broaden geography or model complexity only when the held-out evidence supports it.

Predicting an indicator anomaly, detecting clearing, attributing a driver, estimating resilience statistics and establishing an irreversible ecological tipping point are different claims. Passing tests or producing a map does not establish any stronger claim. See [RESEARCH_PROTOCOL.md](RESEARCH_PROTOCOL.md) for experimental controls and [OPERATOR_GUIDE.md](OPERATOR_GUIDE.md) for local setup, limits, recovery and rollback.
